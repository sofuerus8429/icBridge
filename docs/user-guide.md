# 使用指南

## 运行与卸载

`dist/0.4.7/MicBridge.exe` 为精简单文件，约 2.3 MB，内置完整 VB-CABLE 包，运行所需依赖在内存中加载。使用系统已有的 .NET Framework 4.8；Windows 11 和 Windows 10 1903 及以上无需另装该框架。推荐 Windows 11，进程采集要求系统 build 20348 及以上。

可选 `Uninstall-MicBridge.exe` 与主 EXE 放在同一目录，双击打开卸载窗口；也可以从高级设置点“卸载与清理”。先停止混音并关闭其他音桥实例。勾选驱动卸载会打开官方工具，需要批准管理员请求并在官方窗口点 Remove Driver，然后按提示重启；仅清除设置不需要卸载驱动。歌曲文件不会删除。

音桥本体是便携程序，退出后删除主 EXE 和卸载入口即可；不会创建常驻服务或开机自启。VB-CABLE 是系统共享驱动，卸载后其他使用该线缆的软件也会失去这些端口。

## 三路调音台

需要免装额外虚拟驱动时，在高级设置勾选“使用声卡立体声混音”。只有提供此录音端点的声卡支持；被禁用时点击“打开录音设备”，显示已禁用的设备并启用。游戏麦克风选同一个立体声混音。首次播放会自动验证实际录回路径，必要时选择能录回的端口；高级设置也可点“检测并选择可用输出”。检测会播放短暂低音量提示音，不保存录音，可点“取消检测”结束。

成功验证的端口在本次运行中缓存，重复播放不再发出测试音。设备发生变化后缓存失效，重新打开软件也会重新验证。Windows 的播放端或立体声混音静音、音量为零时，会阻止启动并提示恢复；软件不会替你改系统音量。

此模式会把同声卡上的其他播放声音也录进去，可能包含游戏声、原音乐程序直出，造成重复或无法用音桥总静音完全关闭。要独立控制，请把游戏和音乐程序的播放移到其他声卡/USB 耳机，并关闭 Windows“侦听此设备”。没有合适的录音端或无法隔离其他声音时，取消该模式，使用下述虚拟线缆。不同电脑的声卡能力和可录回端口不同；本机 Realtek 仅扬声器端通过，耳机端不支持。

上方从左到右选择原麦克风、音乐来源和输出设备；下方从左到右是原麦克风、音乐 / 进程和总输出三个竖向推子。点击麦克风或输出下拉框选择设备，选项较多时可滚动。设备在停止混音后更改。

使用 VB-CABLE 时，音桥右上输出选 `CABLE Input`，游戏或录音软件的麦克风选 `CABLE Output`。普通播放设备可用于试听，但不会变成虚拟麦克风。

Windows 的默认播放建议选择真实耳机或扬声器。若设为 CABLE Input，其他程序会直接进入虚拟麦克风，绕过音桥的推子和总静音；主界面会提示恢复默认播放。音桥不会替你更改 Windows 默认设备。

**请勿禁用 CABLE Output，它就是虚拟麦克风。** 名称中的 Output 指线缆输出到录音端；它位于 Windows 的输入设备中。找不到时，在 Windows 声音设置 → 所有声音设备 → 输入设备中允许 CABLE Output，再刷新音桥。Windows 10 可打开 `mmsys.cpl`，在“录制”页右键显示禁用设备，再启用 CABLE Output。CABLE Input 也需保持启用。

默认只显示普通双声道 CABLE Input。官方驱动额外提供的 16ch 多通道端口无需选用；高级设置中的“显示其他输出设备”可以展开其他端口及普通扬声器。应用不修改官方驱动或擅自禁用系统设备。

拖动推子实时调音量。普通模式范围是 0–100%；勾选通道下方的 **GAIN**，该路上限变成 300%，即三倍振幅。取消 GAIN 时，超过 100% 的音量回落到 100%。本地和进程分别保留自己的推子位置与增益模式。

每路“启用”控制是否加入混音，“静音”即时关闭该路声音。推子旁的细分段拾音灯从下向上随实际信号跳动，显示推子调节后的电平；右侧总输出灯显示峰值保护后的最终输出。灯柱范围为 −60 至 0 dBFS，绿色表示较低电平，−12 dBFS 起为黄色，−3 dBFS 起为红色。红色表示接近数字满刻度。静音后该路灯柱会衰减熄灭，数字电平同步归零。

界面采用黑白、圆角和半透明卡片。支持的 Windows 11 使用系统 Acrylic 毛玻璃背景；其他环境保留深色玻璃主题。

## 本地音乐

音乐来源选“本地”，点击来源按钮选择文件，然后点击底部“播放”。底部显示时间与进度，可拖动进度跳转。也可将音乐文件拖入窗口。

“暂停”保留文件进度，原麦克风继续混入；“停止混音”停止输出图并暂停文件，不自动回到开头。高级设置“停止歌曲”会回到开头。切换来源或选择新文件会先停止当前输出，选好后重新播放。

高级设置的“本地播放列表”支持批量添加、移除、双击播放、上一首/下一首和单曲循环。关闭循环时按列表顺序播放，列表结束后停止歌曲。

## 网易云或其他进程

音乐来源选“进程”，点击来源按钮打开选择窗口。默认列出全部 Windows 进程，包括系统、其他会话和没有窗口的后台进程。可搜索进程名（如 `cloudmusic` 或 `cloudmusic.exe`）、窗口标题或 PID。

网易云优先选择有窗口的 `cloudmusic` 主进程，点击“用作声音源”，再点击“启动混音”。采集包含它的播放子进程。虚拟线缆模式无需更改网易云输出设备；声卡立体声混音模式需避免播放器直出和混音同时进入同一个录音端。网易云歌曲的播放、暂停仍由网易云控制；音桥“停止混音”停止转发。

“仅显示有音频会话的进程”是可选筛选，默认关闭。存在会话不代表正在播放；主进程也可能由子进程发声。音桥自身和系统空闲进程显示为不可采集，受系统限制的进程可能无法采集。

选择和启动前核对进程启动时间。播放器退出或重启后，刷新列表并重新选择。指定进程模式不会自动混入无关程序和游戏声音。

旧版 Windows 可在高级设置选“整个播放设备（兼容模式）”，采集所选播放设备的全部声音。采集、输出和监听必须使用不同设备。

## 高级设置

空闲时电平采样停止；最小化会降低显示刷新频率，音频采集继续运行。

右上角“高级设置”包含以下选项：

- 设备与连接：刷新、采集模式、兼容设备、输出缓冲、耳机监听、监听音量和实际混音格式。
- 混音细节：与主界面同步的推子、GAIN、精细 −24 至 +24 dB 增益、音乐 / 人声交叉混音和峰值保护状态。
- 麦克风处理：可选 80 Hz 高通、静音门和门限，默认关闭。
- 本地播放列表：曲目、顺序、循环和播放控制。

“设备与连接”页的“开源许可”可查看软件与内置运行时的授权说明。

缺少虚拟播放或录音设备时，“安装虚拟麦克风”会打开内置 VB-CABLE 安装界面；已有虚拟麦克风时此按钮禁用。首次打开音桥也会检查并提供安装入口。

内部混音固定为 48 kHz、32-bit float、立体声，来源自动重采样。格式展示不是采样率切换功能。

音乐 / 人声交叉混音在中点保留两路完整音量；左端只保留音乐，右端只保留人声。它在独立推子和 dB 增益之外计算。

80 Hz 高通减轻低频轰鸣。静音门会在输入低于门限后保持约 120 ms，再平滑衰减；高于门限时平滑打开。默认门限 −50 dBFS，门限过高可能截断轻声。静音门不消除说话期间的背景噪声。

分路音量、增益、静音和麦克风处理可实时调整；设备、监听开关和采集模式需要停止混音。点击“完成”返回并保存设置。

## 常见问题

**单 EXE 怎么运行：** 在 Windows 11 / Windows 10 1903 及以上双击 `MicBridge.exe`，使用系统内置的 .NET Framework 4.8，无需随附 DLL，也不会解压 .NET 运行时缓存。EXE 包含完整 VB-CABLE 官方包，首次使用可以在音桥内开始安装；仅开始安装时释放驱动安装文件。

**没有虚拟设备：** 点击安装界面的“安装虚拟麦克风”，批准 Windows 的管理员请求，再在 VB-CABLE 官方安装器点击 Install Driver。按提示重启后重新打开音桥。也可在高级设置安装或访问官网。拒绝管理员请求会取消安装，音桥仍可用于普通设备试听。

**注册表会变化吗：** 音桥配置使用 JSON 文件，不主动写注册表。安装虚拟音频驱动会写入设备、驱动相关注册表项；不需要手动修改注册表。卸载驱动应使用官方安装器，而不是只删除音桥 EXE。

**临时安装文件：** 仅点击安装时才从内置包释放文件，官方安装器退出后尝试删除本次临时目录。无法删除时显示目录位置，安装所需的系统驱动文件继续保留。

**只想播放音乐：** 关闭左侧麦克风通道的“启用”，或将它静音。

**听不到歌曲：** 虚拟输出通常不会直接播放到扬声器。高级设置可开启耳机监听并选择真实耳机；检查通道启用、静音和交叉混音位置。

**有回声：** 使用耳机，关闭 Windows“侦听此设备”，避免将游戏语音输出再次采集到同一个虚拟输入。

**300% 仍不够响：** 查看输入电平和总输出推子。很响的输入会触发峰值保护；300% 是振幅倍数，不能绕过数字满刻度。高级 dB 增益会另外叠加，过度提高会压缩动态。

**游戏里音乐很小或断续：** 检查游戏的降噪、自动增益、回声消除、语音激活阈值和按键说话。

**延迟高或卡顿：** 进程采集自动使用 Windows 音频调度，无需手动设置。默认输出缓冲 60 ms，必要时调到 80–120 ms。实际延迟还包括采集、虚拟驱动与游戏语音处理。

`Ctrl+O` 添加音乐，`Ctrl+M` 切换总静音，仅在音桥窗口内生效。设置保存在 `%LOCALAPPDATA%/MicBridge/settings.json`，错误日志位于同目录。程序不自动开始采集，不保存或上传音频。

多个音桥窗口共享此配置，最后一次成功保存的设置生效。加载和保存时短暂协调访问；若另一个实例长时间占用，会提示稍后重试。关闭其他实例后再卸载或清除设置。卸载清理会识别旧版暂存文件及新版生成的暂存文件，不按通配符删除任意 `.tmp` 文件。
