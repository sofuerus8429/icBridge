# MicBridge 音桥 v0.4.7

Windows 音频混音工具，可把本地音乐或选定进程及其子进程的声音与原麦克风叠加，送到游戏可选的录音端。主界面提供三路竖向推子、分段拾音灯和静音按钮，每路可切换 GAIN，推子最高 300%。

本版进程采集使用 Windows Audio 多媒体调度，停止或异常退出时释放登记；注册失败时继续普通采集，不增加正式运行线程，不修改系统计时器或调度注册表。

## 下载与运行

- `MicBridge.exe`：Windows x64 单文件，2,327,040 字节，约 2.33 MB。使用系统 .NET Framework 4.8，无需旁侧 DLL。
- `MicBridge-0.4.7-win-x64.zip`：主程序、可选卸载入口、使用与配置说明。
- `MicBridge-0.4.7-source.zip`：与本次发布标签一致的源码及文档。
- `MicBridge-0.4.7-configuration.md`：可单独下载的新手配置说明，包含设备映射、禁用恢复和工作原理。
- `Uninstall-MicBridge.exe`：可选卸载入口，需放在主 EXE 旁；也可从主程序高级设置打开卸载窗口。

推荐 Windows 11。指定进程采集要求 Windows build 20348 或以上；Windows 10 22H2 可使用本地文件、麦克风和整个播放设备的兼容采集。

## 驱动与连接

完整官方 VB-CABLE Pack45 已内置。新电脑缺少虚拟设备时，用户主动点击安装入口才会启动官方安装器并请求管理员批准，安装完成后按提示重启。音桥输出选择 **CABLE Input**，游戏输入选择 **CABLE Output**，请保持这两个端点启用。

**请勿在 Windows 中禁用 CABLE Output。** 首次使用、网易云进程选择、设备恢复和工作原理见[新手配置说明](https://github.com/sofuerus8429/icBridge/blob/main/docs/configuration.md)。

声卡已有可用“立体声混音”时，可使用现有声卡模式，省去额外虚拟驱动；该模式依赖声卡能力，并会录入同一声卡上的其他播放声音。

## 验证

net48 与 net8.0-windows 各通过 95 项行为测试，共 190 次执行。最终单 EXE 在隔离目录中通过 12 项发行检查，包括 WAV/MP3/M4A 播放、真实虚拟麦克风录回、四个工作线程负载下的进程隔离与静音恢复，以及连接取消、麦克风启停和配置检查。

本轮未重复三分钟文件持续录回，该阶段沿用 v0.4.5 结果；没有进行游戏内测试。具体条件与边界见[验证记录](https://github.com/sofuerus8429/icBridge/blob/main/docs/verification.md)。
